# Домашнее задание к работе 7

## Условие задачи
Составить программу, которая по названию фигуры (треугольник - t, квадрат - s, круг - o, прямоугольник - r и т.п.) вычисляет площадь этой фигуры, необходимые значения задаются пользователем.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Устанавливаем кодировку UTF-8, чтобы русский текст в консоли выводился корректно.
3. Запрашиваем у пользователя символ `fig`, который указывает на тип фигуры (t, s, o или r).
4. В зависимости от введенного символа (конструкция `switch`), выполняем расчет площади:
   - Если `fig == 't'` (треугольник): запрашиваем основание и высоту, затем считаем площадь как половину их произведения: S = 0.5 * a * h.
   - Если `fig == 's'` (квадрат): запрашиваем длину стороны и возводим ее в квадрат: S = a * a.
   - Если `fig == 'o'` (круг): запрашиваем радиус и считаем площадь через число Пи (примерно 3.14159): S = 3.14159 * r * r.
   - Если `fig == 'r'` (прямоугольник): запрашиваем длину и ширину, перемножаем их: S = a * b.
   - Если введен любой другой символ (блок `default`), выводим сообщение об ошибке «Ошибка: неизвестная фигура».
5. Показываем вычисленную площадь на экране.
6. **Конец**.

**Часть 2: Расчетные функции (для каждой фигуры)**
1. **Начало функции**: принимаем нужные параметры (размеры сторон или радиус).
2. Выполняем математические действия (умножение, возведение в квадрат).
3. Возвращаем полученное значение площади обратно в функцию `main`.
4. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

float s_tri(float a, float h);
float s_sq(float a);
float s_circ(float r);
float s_rect(float a, float b);

int main()
{
    char fig;
    float a, b, h, r, s;

    setlocale(LC_ALL, ".UTF8");

    printf("Введите фигуру (t - треугольник, s - квадрат, o - круг, r - прямоугольник): ");
    scanf(" %c", &fig);

    switch (fig)
    {
        case 't':
            printf("Введите основание и высоту: ");
            scanf("%f %f", &a, &h);
            if (a <= 0 || h <= 0) {
                printf("Ошибка: размеры должны быть положительными\n");
                return 0;
            }
            s = s_tri(a, h);
            printf("Площадь треугольника: %.2f\n", s);
            break;

        case 's':
            printf("Введите сторону: ");
            scanf("%f", &a);
            if (a <= 0) {
                printf("Ошибка: сторона должна быть положительной\n");
                return 0;
            }
            s = s_sq(a);
            printf("Площадь квадрата: %.2f\n", s);
            break;

        case 'o':
            printf("Введите радиус: ");
            scanf("%f", &r);
            if (r <= 0) {
                printf("Ошибка: радиус должен быть положительным\n");
                return 0;
            }
            s = s_circ(r);
            printf("Площадь круга: %.2f\n", s);
            break;

        case 'r':
            printf("Введите длину и ширину: ");
            scanf("%f %f", &a, &b);
            if (a <= 0 || b <= 0) {
                printf("Ошибка: размеры должны быть положительными\n");
                return 0;
            }
            s = s_rect(a, b);
            printf("Площадь прямоугольника: %.2f\n", s);
            break;

        default:
            printf("Ошибка: неизвестная фигура\n");
            break;
    }
    return 0;
}

float s_tri(float a, float h) {
    return 0.5f * a * h;
}

float s_sq(float a) {
    return a * a;
}

float s_circ(float r) {
    return 3.14159265f * r * r;
}

float s_rect(float a, float b) {
    return a * b;
}
```
