# Домашнее задание к работе 7

## Условие задачи
Составить программу, которая по названию фигуры (треугольник - t, квадрат - s, круг - o, прямоугольник - r и т.п.) вычисляет площадь этой фигуры, необходимые значения задаются пользователем.

## 1. Математическая модель

Перед написанием программы определим формулы для вычисления площади каждой из фигур, которые будут использоваться в коде:

**1. Треугольник (обозначение 't'):**
Площадь вычисляется через основание (\(a\)) и высоту (\(h\)), проведенную к этому основанию:
S = 0.5 * a * h

**2. Квадрат (обозначение 's'):**
Площадь равна квадрату длины его стороны (\(a\)):
S = a * a


**3. Круг (обозначение 'o'):**
Площадь вычисляется через радиус (\(r\)) с использованием математической константы \(\pi\) (число пи):
(π = 3.14159265):
S = 3.14159265 * r * r



**4. Прямоугольник (обозначение 'r'):**
Площадь равна произведению его смежных сторон — длины (\(a\)) и ширины (\(b\)):
S = a * b

### Блок-схема
тут блоксхему нада

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#include <math.h>

int main()
{
    char fig;
    float a, b, h, r, s;

    // Устанавливаем локаль для поддержки русского языка
    setlocale(LC_ALL, ".UTF8");

    printf("Введите фигуру (t - треугольник, s - квадрат, o - круг, r - прямоугольник): ");
    scanf(" %c", &fig);

    switch (fig)
    {
        case 't':
            printf("Введите основание и высоту: ");
            scanf("%f %f", &a, &h);
            s = 0.5 * a * h;
            printf("Площадь треугольника: %.2f\n", s);
            break;
        case 's':
            printf("Введите сторону: ");
            scanf("%f", &a);
            s = a * a;
            printf("Площадь квадрата: %.2f\n", s);
            break;
        case 'o':
            printf("Введите радиус: ");
            scanf("%f", &r);
            s = 3.14159265 * r * r;
            printf("Площадь круга: %.2f\n", s);
            break;
        case 'r':
            printf("Введите длину и ширину: ");
            scanf("%f %f", &a, &b);
            s = a * b;
            printf("Площадь прямоугольника: %.2f\n", s);
            break;
        default:
            printf("Ошибка: неизвестная фигура\n");
            break;
    }
    return 0;
}
```
